Installation:

---------------------

Client side:
- Copy the contents of the zip file to KSP folder. So in KSP/GameData folder you have both "VladMultiplayer" and "000_Harmony" folders

DO NOT put the standalone server in your GameData folder!!!

Server side:
- Copy the published "Server" output folder to any location of your choice EXCEPT the KSP folder. Put it preferably on C:/ or in your Desktop

--------------------

Remember: Multiplayer and heavily modded installs can interact badly. Test VMP with the smallest mod set possible first.
